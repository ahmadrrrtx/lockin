# Screenshots

This folder is intentionally empty in the repository.

The build host used for v1.0.x/1.1.0 has **no Android device and no hardware-accelerated
emulator**, and Lockin does not ship mockups presented as screenshots. Capture the
real set with the exact commands in [`../SCREENSHOT_PROCEDURE.md`](../SCREENSHOT_PROCEDURE.md)
on any machine with a device or emulator, and commit the resulting PNGs here.
